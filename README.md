# Classical Play-Along

Play the tune of classical pieces on an on-screen piano while cellos and a
double bass accompany you. Falling blocks show which key to press next.

**Play it:** https://mchughde.github.io/classical-play-along-web/

On an iPad, open that address in Safari, then Share → Add to Home Screen.
After the first visit it also works offline.

This repository holds only the published page; it is generated from a
separate project and overwritten on each publish.
